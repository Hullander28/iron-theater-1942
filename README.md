# Iron Theater 1942
Mobile-friendly WWII grand-strategy board game (HTML5 PWA): 5 powers, two coalitions, IPC economy, land/sea/air combat, amphibious assaults, plastic army-men pieces, AI (Easy–Brutal), pass-and-play and online rooms (PeerJS, host-authoritative) with pause/resume.
